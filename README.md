# Как доказать окупаемость ИИ-проекта, не зная маржи клиента

Портфолио-кейс по обоснованию стратегического проекта: как сделать видимой цену
бездействия и превратить окупаемость ИИ-проекта в неравенство, которое клиент
проверяет по своей экономике. Проект — фильтр для грузовой авиакомпании,
который отличает запросы на перевозку от остальной почты и сам создаёт лиды в
CRM. Осень 2025 года, договор подписан, система внедрена.

**Страница кейса:** [massimo-pazzi.github.io/b2b-value-case](https://massimo-pazzi.github.io/b2b-value-case/)
**Дашборд в Yandex DataLens:** [datalens.yandex/kpjn9qs3sice3](https://datalens.yandex/kpjn9qs3sice3)

Клиент и подрядчик не называются. Стоимостные показатели изменены по
соображениям конфиденциальности; логика расчёта сохранена.

## Структура

```
index.html              страница кейса (собирается скриптом)
report/case.md          текст кейса
scripts/model.py        модель: стоимость, выгоды, окупаемость, пороговая маржа, чувствительность
scripts/build_page.py   сборка страницы из текста и модели
data/                   результаты модели в CSV (для страницы и Yandex DataLens)
```

## Как пересчитать

```bash
python3 scripts/model.py
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_page.py
```

Все допущения — в начале `scripts/model.py`, у каждого указано происхождение.
